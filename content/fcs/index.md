The Forgotten Construction Set is the starting point for editing Kenshi's game
data. Begin with the interface guide, then follow a focused workflow.

## Start here

- [[modding/fcs/using-the-fcs|Using the FCS]] explains launching the editor,
  choosing an active mod, and navigating objects and columns.
- [[modding/fcs/searching-and-editing-data|FCS Searches and Bulk Editing]] covers
  property filters, recursive references, and editing tools.
- [[modding/fcs/managing-mods|FCS Mod Management]] covers load order, merge choices,
  cleanup, and the Steam connection requirement.
- [[modding/fcs/checking-mod-errors|FCS Error Checking]] explains error inspection
  and all 17 error types documented in the source.

These concise guides adapt Kenshi Wiki's Using the FCS article; attribution and
the text license are on [[credits#using-the-fcs-text-license|Credits]].
[[modding/fcs/complete-guide|The FCS - A Complete Guide]] remains available as the
older extended compilation, with its original migration notices intact.
