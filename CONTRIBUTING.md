# Contributing

The [GitHub Wiki](https://github.com/Atlasroar/Kenshi-Modding-Wiki/wiki) is the
website knowledge base. Start with
[Contributing](https://github.com/Atlasroar/Kenshi-Modding-Wiki/wiki/Contributing),
[Writing Guides](https://github.com/Atlasroar/Kenshi-Modding-Wiki/wiki/Writing-Guides),
or [CSS and Theme](https://github.com/Atlasroar/Kenshi-Modding-Wiki/wiki/CSS-and-Theme).

The public website is for modding guides. Keep website setup, CSS, JSON,
configuration, and maintainer documentation in the Wiki, not `content/`.
Never commit private notes or credentials to either repository.

## Reporting and submitting

Choose a dedicated form when [opening an issue](https://github.com/Atlasroar/Kenshi-Modding-Wiki/issues/new/choose):

- **Site error:** loading, links, navigation, search, layout, accessibility,
  media display, graph/reader mode, comments, social previews, or build failures.
- **New page submission or request:** modding-guide or technical Wiki drafts
  and requests for missing coverage.
- **Media submission:** new illustrations, missing-image restoration, or
  replacements with source and reuse-rights information.
- **Correction:** inaccurate or outdated instructions, examples, wording,
  warnings, or attribution.
- **Feature or site improvement:** new capabilities, usability, contribution
  workflows, and repository maintenance.

General modding questions belong in
[Discussions](https://github.com/Atlasroar/Kenshi-Modding-Wiki/discussions).
Drafts and media require maintainer review before publication; unclear reuse
rights should be raised with a public source link, not an unauthorized copy.
Blank issues remain available for reports that do not fit a form.
