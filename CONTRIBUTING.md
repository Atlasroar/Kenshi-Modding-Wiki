# Contributing

The [GitHub Wiki](https://github.com/Atlasroar/Kenshi-Modding-Wiki/wiki) is the
website knowledge base. Start with
[Contributing](https://github.com/Atlasroar/Kenshi-Modding-Wiki/wiki/Contributing),
[Writing Guides](https://github.com/Atlasroar/Kenshi-Modding-Wiki/wiki/Writing-Guides),
or [CSS and Theme](https://github.com/Atlasroar/Kenshi-Modding-Wiki/wiki/CSS-and-Theme).

The public website is for modding guides. Keep website setup, CSS, JSON,
configuration, and maintainer documentation in the Wiki, not `content/`.
Never commit private notes or credentials to either repository.
